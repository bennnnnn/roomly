# Architecture Decision Records

Each ADR records one decision: the context, the options considered, and the chosen path with the rationale. Numbered sequentially. Never rewrite an ADR — supersede it with a new one and link them.

Template:

```markdown
# ADR-NNNN — <title>

- **Status**: proposed | accepted | superseded by ADR-XXXX
- **Date**: YYYY-MM-DD
- **Owners**: <names>

## Context

<problem and forces>

## Options

1. <option A>
2. <option B>

## Decision

<chosen option and why>

## Consequences

<positive + negative>
```
